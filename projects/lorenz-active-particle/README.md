# Deterministic Lorenz Active Particle

> Statistical mechanics of a constant-speed one-dimensional active particle driven by deterministic Lorenz reversals.

## Core Research Questions

1. Which stationary, relaxation, and first-passage properties of a stochastic
   run-and-tumble particle survive when Poisson reversals are replaced by deterministic
   Lorenz-attractor crossings?
2. Can the leading statistics be predicted by the substitution
   $\gamma\mapsto\gamma_{\rm eff}$, and where do Lorenz correlations invalidate it?
